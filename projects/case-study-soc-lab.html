SOC Simulation Lab

SIEM Deployment & Threat Detection

📅 2024 ⏱️ SIEM, Threat Detection 🏷️ Wazuh, MITRE ATT&CK

🎯 Project Overview

Built an isolated VMware-based Security Operations Center (SOC) simulation lab using Wazuh SIEM to detect and respond to SSH brute force attacks in real-time. This project demonstrates practical implementation of enterprise-grade security monitoring in a controlled environment.

🔍 Challenges & Objectives

  • Create a realistic attack simulation environment without affecting production systems
  • Implement real-time threat detection with minimal false positives
  • Map findings to industry frameworks (NIST CSF 2.0, MITRE ATT&CK)
  • Develop alert correlation rules for effective incident response

🛠️ Technical Implementation

Lab Architecture

The lab consists of three isolated virtual machines running on VMware:

  • Wazuh Manager (Ubuntu 22.04): Central SIEM server for log collection and analysis
  • Attack Machine (Kali Linux): Simulates threat actor conducting SSH brute force attacks
  • Target Machine (Ubuntu): Victim system with SSH service exposed

Key Components

Wazuh 4.7.5 Ubuntu 22.04 Kali Linux Syslog NIST CSF 2.0 MITRE ATT&CK

Implementation Steps

  1. Deployed Wazuh manager with default configuration
  2. Configured Wazuh agents on target and attack machines
  3. Implemented syslog forwarding from Kali Linux to Wazuh
  4. Created custom decoders and rules for SSH brute force detection
  5. Set up alert correlation to identify attack patterns
  6. Integrated MITRE ATT&CK mapping for T1110.001 (Brute Force: Password Guessing)

📊 Results & Findings

Real-time Detection

Successfully detected SSH brute force attempts within 5 seconds of initiation

Alert Accuracy

Achieved 95% accuracy with minimal false positives through tuned correlation rules

Framework Mapping

All findings mapped to NIST CSF 2.0 functions and MITRE ATT&CK techniques

💡 Key Learnings

  • Importance of log normalization in multi-vendor environments
  • Balance between detection sensitivity and false positive rates
  • Value of framework mapping for compliance and incident reporting
  • Practical challenges in deploying SIEM in isolated networks
