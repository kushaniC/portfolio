Peak Forecasting ML

Machine Learning & Analytics

📅 2024 ⏱️ ML Project 🏷️ Python, TensorFlow

🎯 Project Overview

Developed a predictive framework for electricity peak demand forecasting using approximately 2 million records from the UCI repository. Built a comprehensive preprocessing pipeline and evaluated multiple machine learning models, achieving an exceptional 0.998 R² score with Random Forest.

🔍 Project Objectives

  • Predict household electricity peak demand with high accuracy
  • Process and clean large-scale time-series data (~2M records)
  • Compare multiple ML algorithms for optimal performance
  • Create a scalable preprocessing pipeline
  • Provide actionable insights for energy management

🛠️ Technical Stack

Python TensorFlow Scikit-learn Pandas Matplotlib NumPy

📊 Data Preprocessing Pipeline

Key Steps

  1. Data Cleaning: Handled missing values through interpolation techniques
  2. Outlier Detection: Applied IQR (Interquartile Range) method to identify and handle outliers
  3. Feature Engineering: Created time-based features (hour, day, month, season)
  4. Dimensionality Reduction: Implemented PCA (Principal Component Analysis) for feature optimization
  5. Normalization: Scaled features for optimal model performance
  6. Train-Test Split: 80-20 split with time-series validation

🤖 Models Evaluated

  • LSTM (Long Short-Term Memory): Deep learning approach for time-series forecasting
  • SVR (Support Vector Regression): Kernel-based regression method
  • Decision Tree: Tree-based ensemble method
  • Random Forest: Ensemble learning with multiple decision trees

📈 Performance Metrics

Model R² Score RMSE MAE
Random Forest 0.998 0.042 0.031
LSTM 0.985 0.089 0.067
SVR 0.972 0.124 0.095
