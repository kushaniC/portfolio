AutoReconLite

Reconnaissance & Vulnerability Scanner

📅 2024 ⏱️ Automation Tool 🏷️ Bash, Nmap

🎯 Project Overview

Developed a modular Bash-based penetration testing framework that automates TCP SYN scanning, service detection, and OS fingerprinting using Nmap NSE scripts. The tool features flexible scan modes with automated report generation and audit logging.

🔍 Key Features

  • Modular Architecture: Each scanning function is modular for easy maintenance and updates
  • Flexible Scan Modes: Quick scan for rapid assessment, full scan for comprehensive analysis
  • TCP SYN Scanning: Stealth scanning technique to avoid detection
  • Service Detection: Automatic identification of running services and versions
  • OS Fingerprinting: Target operating system identification using Nmap NSE scripts
  • Color-coded CLI: Enhanced usability with color-coded output for different severity levels
  • Automated Reporting: Generates detailed reports in multiple formats
  • Audit Logging: Complete audit trail of all scanning activities

🛠️ Technical Stack

Bash Nmap Linux CLI Tools NSE Scripts

💻 Usage Example

# Quick scan mode ./autoreconlite.sh -t 192.168.1.100 -m quick # Full scan with report generation ./autoreconlite.sh -t 192.168.1.100 -m full -o report.txt # Custom port range scan ./autoreconlite.sh -t 192.168.1.100 -p 1-1000
